# 🏋️‍♂️ Dark Neon Fitness Portal

Welcome to my **very first web development project**! 🎉 

This is a modern, high-performance, and fully responsive gym website designed from scratch. It features a sleek dark-mode aesthetic paired with vibrant neon purple accents, built specifically for fitness centers, gym clubs, and personal trainers.

---

## 🌟 Highlights & Achievements

* **First Project Milestone:** Built from the ground up as my debut hands-on project in web development.
* **Modern Aesthetic:** Custom Dark Mode with Neon Purple branding.
* **Pure Fundamentals:** Structured cleanly using native web technologies without relying on heavy frameworks.
* **Fully Responsive:** Layout engineered to adapt smoothly across all device sizes.

---

## ✨ Features & Sections

1. **Navbar & Hero Section:** High-impact introduction with quick call-to-action buttons.
2. **Why Choose Us & Services:** Overview of offered fitness programs and facility perks.
3. **Interactive Pricing Table:** Clean 3-tier membership plan with a featured "Pro" option.
4. **Leadership & Team Showcase:** Parallax-backed profile section for management and specialized coaches with social icons.
5. **Interactive Testimonials:** Student and member success stories integrated over parallax backgrounds.
6. **Fitness & Health Blog:** Informative articles covering nutrition, workout strategies, and injury prevention.

---

## 🎨 Design System

* **Theme:** Dark Mode + Neon Accents
* **Background:** `#121212` (Dark Charcoal)
* **Containers / Cards:** `#1E1E2A` (Deep Slate)
* **Primary Accent:** `#915EDD` (Neon Purple)
* **Text Colors:** `#FFFFFF` (Headings) / `#A0A0B0` (Secondary Body Text)

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom styling utilizing Flexbox, hover transitions, and Parallax effects.
